말한 내용을 받아쓰고, 선택한 언어(스페인어·영어 등)로 번역한 뒤, 브라우저 내장 음성 합성으로 읽어 줍니다. 번역문 발음을 직접 들을 수 있습니다.

이 브라우저는 Web Speech API를 지원하지 않습니다.
Chrome, Edge, Safari(14+)에서 열어 주세요. Firefox는 음성 인식을 기본 미지원합니다.

스페인어 발음을 들으려면

  • 음성 목록에서 Spanish / Español 항목을 고르세요 (자동 선택됩니다)
  • 목록에 스페인어가 없으면 OS에 음성팩 설치가 필요합니다
  • Windows: 설정 → 시간 및 언어 → 음성 → 음성 추가
  • 속도 0.8 전후로 낮추면 발음 학습에 유리합니다

동작 방식과 제약

  • TTS(speechSynthesis)는 브라우저 내장이라 외부 전송이 없습니다
  • 번역만 외부 엔드포인트를 쓰며, API 키는 필요 없습니다
  • HTTPS 또는 localhost에서만 마이크가 동작합니다
  • Space=녹음 토글, Esc=재생 정지
